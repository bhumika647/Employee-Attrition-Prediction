# Employee Attrition Prediction Using Machine Learning

## Project Overview

Employee Attrition Prediction is a machine learning classification project that aims to predict whether an employee is likely to leave an organization based on various employee-related factors.

The project focuses on data analysis, preprocessing, handling imbalanced data, and building machine learning models for accurate attrition prediction.

## Problem Type

Binary Classification

## Target Variable

Attrition (Yes/No)

## Machine Learning Workflow

- Exploratory Data Analysis (EDA) to identify patterns and relationships in employee data
- Data preprocessing and feature transformation
- Handling class imbalance using oversampling and undersampling techniques
- Dimensionality reduction using Principal Component Analysis (PCA)
- Model training and performance evaluation

## Model Performance

The best performance was achieved using PCA with oversampling techniques.

## Performance Metrics:

- Accuracy: 89.2%
- Precision: 90.6%
- Recall: 87.4%
- F1 Score: 92.2%
